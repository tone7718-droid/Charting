# 도수치료 진료 기록지 입력 도우미

2026년 7월 1일부터 시행 중인 **도수치료 관리급여** 기준에 따라 진료 차트에 입력해야 하는
항목들을 마우스 클릭 위주로 빠르고 일관된 형식으로 작성하는 Windows 프로그램입니다.

핵심 사용 흐름:

**항목 입력·선택 → 진료기록 자동 생성 → 누락 항목 확인 → 전체 복사 → 진료 차트에 붙여넣기**

```
진단명 : M751 회전근개증후군
치료목적 : 통증 감소, 자세 교정, 관절가동범위 개선
시행자 : 홍길동 물리치료사
시행일시 : 2026년 07월 03일
시행횟수 : 3회차
시행부위 : 허리
시행기법 : Myofascial Release, Stabilization Exercise
치료시간 : 30분
```

## 설치 방법 (EXE 다운로드)

코드가 push될 때마다 GitHub이 자동으로 Windows용 실행 파일을 빌드합니다.

1. **Releases 페이지에서 바로 다운로드 (권장, 로그인 불필요)**:
   https://github.com/tone7718-droid/Charting/releases/tag/latest
   - `TherapyChartSetup.exe` — 설치 프로그램 (바탕화면 바로가기 생성)
   - `TherapyChart.exe` — 설치 없이 바로 실행
2. 또는 GitHub 저장소의 **Actions** 탭(로그인 필요) → 가장 최근의 **Build Windows EXE** 실행 클릭
   → 하단 **Artifacts**에서 `TherapyChart-installer` 또는 `TherapyChart-exe` 다운로드
3. Python 등 별도 프로그램 설치가 필요 없으며, 인터넷 연결 없이 동작합니다.

> 처음 실행 시 Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.
> (서명되지 않은 프로그램에 대한 일반적인 경고입니다.)

## 화면 구성

실행하면 화면이 **좌우 50:50**으로 나뉩니다 (가운데 경계를 드래그해 비율 조절 가능).
왼쪽에서 입력·선택하면 오른쪽 미리보기가 즉시 갱신됩니다.

| 왼쪽 항목 | 사용 방법 |
|---|---|
| ① 진단명 | 진단코드/진단명 직접 입력 (소문자 코드는 자동 대문자 변환: m751→M751), 최근 사용 드롭다운, 저장 목록 검색 후 클릭 |
| ② 치료목적 | 토글 버튼 다중 선택 (클릭한 순서대로 쉼표 구분 출력) |
| ③ 시행자 | 드롭다운에서 치료사 선택 → "OOO 물리치료사" 자동 출력 (이름에 이미 '물리치료사'가 있으면 중복해서 붙지 않음) |
| ④ 시행일시 | 달력에서 날짜 클릭 → "YYYY년 MM월 DD일" (월·일 두 자리) |
| ⑤ 시행횟수 | 숫자 전용 스핀박스 (최솟값 1, '회차' 자동) |
| ⑤ 시행부위 | 직접 입력 또는 드롭다운(즐겨찾기 + 최근 사용)에서 선택 |
| ⑤ 치료시간 | 기본 30분 (설정 > 데이터 탭에서 변경 가능) |
| ⑥ 시행기법 | 토글 버튼 다중 선택 |

오른쪽 화면:

- **진료 기록 미리보기** — 항목당 한 줄, 지정된 순서·형식으로 자동 생성
- **✏ 직접 수정** — 미리보기를 직접 편집. 편집 중에는 왼쪽 변경이 덮어쓰지 않고
  안내만 표시되며, [자동 생성 내용으로 갱신] 버튼(확인 창 표시)으로 재생성,
  [편집 종료]로 수정 내용을 유지한 채 읽기 전용 복귀
- **📋 전체 복사** (Ctrl+Shift+C) — 필수 항목이 모두 입력된 경우에만 복사.
  누락 시 복사가 차단되고, 해당 항목이 ⚠ 빨간색으로 강조되며
  "필수 항목을 확인해주세요: 시행부위, 시행기법" 형식으로 안내
- **초기화** (Ctrl+R) — 확인 후 현재 환자 입력만 초기화 (치료사·설정·저장 목록은 유지,
  날짜는 오늘, 횟수 1, 시행자는 기본 치료사로)
- **⚙ 설정** — 아래 관리 기능

## 설정 화면

- **치료사**: 추가/이름 수정/삭제, ★ 기본 치료사 지정. 마지막 선택 치료사를 기억하며,
  한 명만 등록된 경우 자동 선택. 첫 실행 시 등록 창이 자동으로 열립니다.
- **치료 목적 / 시행 기법**: 항목 추가/수정/삭제 (기본 제공 항목 삭제 시 확인 창)
- **진단명**: 추가/수정/삭제, ★ 즐겨찾기, 검색(코드·한글명), **CSV 가져오기/내보내기**,
  최근 사용 목록 비우기
- **시행 부위**: 즐겨찾기 관리, 최근 사용 목록 관리
- **데이터**: 저장 위치 확인/폴더 열기, **백업 내보내기/복원**, 창 크기·위치 기억 여부,
  치료시간(분) 변경

### 진단명 CSV 형식

```csv
진단코드,진단명
M751,회전근개증후군
M545,요통
```

첫 줄 헤더는 자동으로 건너뛰며, 엑셀에서 저장한 CSV(BOM 포함)도 정상 처리됩니다.
심평원(KCD) 상병 목록을 파일로 구하면 이 형식으로 일괄 등록할 수 있습니다.

## 데이터 저장

- 저장 위치: `%APPDATA%\TherapyChart\settings.json` (사용자 쓰기 가능 경로)
- 저장 대상: 치료사 목록/기본·마지막 치료사, 치료 목적/시행 기법 항목, 진단명 목록·즐겨찾기·최근 사용,
  시행 부위 즐겨찾기·최근 사용, 치료시간, 창 크기·위치
- **환자 개인정보(이름·주민번호·연락처·차트번호·환자별 기록 등)는 어떤 것도 저장하지 않습니다.**
  이 프로그램은 현재 진료기록 문장을 생성해 클립보드에 복사하는 보조 도구이며,
  프로그램 종료 시 작성 중이던 내용은 저장되지 않습니다.
- 백업: 설정 > 데이터 > 백업 내보내기 (기본 파일명 `manual_therapy_helper_backup_YYYYMMDD.json`).
  복원 시 확인 창이 표시되고, 잘못된 파일이면 기존 데이터를 그대로 유지합니다.

## 기술 스택 선택 이유

- **tkinter** (Python 표준 GUI): PySide6/PyQt6도 검토했으나, 이 규모의 단일 화면 도구에는
  외부 의존성이 전혀 없는 tkinter가 EXE 용량(약 1/5 수준)·빌드 안정성·유지보수 면에서 유리합니다.
- **JSON** (SQLite 대신): 저장 데이터가 수백 건 이하의 문자열 목록이라 관계형 DB가 필요 없고,
  백업/복원이 파일 하나 복사로 끝나며, 문제가 생겨도 메모장으로 열어 확인할 수 있습니다.
- **PyInstaller**: Python 미설치 PC에서 실행 가능한 단일 EXE 생성 (`console=False`로 콘솔창 숨김)
- **Inno Setup**: 설치 경로 선택·바탕화면/시작 메뉴 바로가기·제거 기능을 갖춘 설치 프로그램

## 개발자용

```bash
# 실행 (Windows, Python 3.10+ — tkinter 내장)
python therapy_chart_app.py

# 단위 테스트 (진료기록 생성/검증 + 저장/CSV/백업 로직, 40개)
python -m unittest discover -s tests -v

# EXE 빌드
pip install pyinstaller
pyinstaller TherapyChart.spec        # → dist/TherapyChart.exe

# 설치 프로그램 빌드 (Inno Setup 6 설치 후)
ISCC.exe installer\TherapyChart.iss  # → installer/Output/TherapyChartSetup.exe
```

코드 구조:

```
therapy_chart_app.py          실행 진입점 (PyInstaller 대상)
therapy_chart/
  constants.py                기본 데이터·출력 라벨 (하드코딩 값 모음)
  record.py                   진료기록 생성 + 필수 항목 검증 (UI 독립, 테스트 대상)
  storage.py                  설정 저장(%APPDATA%/JSON), CSV, 백업/복원
  widgets.py                  달력·토글 버튼·스크롤 프레임 공통 위젯
  main_window.py              메인 화면
  settings_dialog.py          설정 창
tests/                        단위 테스트
TherapyChart.spec             PyInstaller 빌드 설정
installer/TherapyChart.iss    Inno Setup 설치 프로그램 스크립트
.github/workflows/            테스트 + EXE + 설치 프로그램 자동 빌드
```

## 2차 개발 예정 (1차 미구현)

- **치료 효과 평가** (주관적 호전도, VAS, ROM, 치료 전후 변화 등)
  — `therapy_chart/record.py`의 `TherapyRecord`에 필드를 추가하고 `build_lines()`에
  출력 줄을 넣은 뒤, `main_window.py`에 입력 UI를 추가하면 됩니다.
- **심평원 진단명 전체 연동** — 공식 API/공공데이터 확인 후 진행.
  그 전에는 KCD 상병 목록 CSV를 구해 "설정 > 진단명 > CSV 가져오기"로 일괄 등록하는 방식을 권장합니다.
- 시행 시간(시각) 입력, EMR 자동 입력, 클라우드 동기화, 자동 업데이트는 범위에서 제외되어 있습니다.

## 알려진 제한 사항

- EXE가 코드 서명되지 않아 첫 실행 시 SmartScreen 경고가 표시될 수 있습니다.
- 설치 프로그램 UI 언어는 영어입니다(설치되는 프로그램 자체는 한국어).
- 직접 수정 모드에서 복사할 때는 필수 항목 검사를 하지 않습니다
  (사용자가 의도적으로 문구를 편집한 것으로 간주).
